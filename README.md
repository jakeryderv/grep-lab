## OVERVIEW

`grep` searches for **pattern(s)** in **file(s)**

***COMMAND STRUCTURE***

```bash
grep [OPTION...] PATTERN [FILE...]
grep [OPTION...] -e PATTERN ... [FILE...]
grep [OPTION...] -f PATTERN_FILE ... [FILE...]
```

```bash
grep 'error' file.txt
```
